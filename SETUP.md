# Setup — Dolly Gupta GitHub Profile

This package recreates the structure/aesthetic of the referenced Gargi profile: dot-matrix portrait, animated typing banner, badges, `~/` terminal sections, toolbox, two radar charts, 3D isometric contribution calendar, snake, GitHub numbers, achievements, selected-work cards and binary footer.

Your project **ShinigamiCode stays untouched**.

## 1. Create the profile repository

Go to:
https://github.com/new

Create a **Public** repository named exactly:

`guptadolly458`

Do not name this repository `ShinigamiCode`. That is your normal project repo.

## 2. Upload everything from this ZIP

Inside `guptadolly458`, upload:

```text
README.md
assets/
.github/
```

Then commit to `main`.

## 3. Enable Actions write permission

Repository → **Settings** → **Actions** → **General**

Under **Workflow permissions**, select:

**Read and write permissions**

Save.

## 4. Set up the Metrics token

The 3D isometric calendar and achievements are generated by `lowlighter/metrics`. Its documentation says a personal GitHub token is required for some user/account data that the repository-scoped `GITHUB_TOKEN` cannot access.

Create a GitHub Personal Access Token from:

GitHub → Settings → Developer settings → Personal access tokens

Use the least permissions necessary for the public metrics you want.

Then go to:

**guptadolly458 → Settings → Secrets and variables → Actions → New repository secret**

Name the secret:

`METRICS_TOKEN`

Paste your token into the value field.

Never put a token into README.md.

## 5. Run the Actions

Open:

**Actions**

You will see:

- Generate Snake
- Generate GitHub Metrics

Click each one → **Run workflow**.

After they finish, refresh:

https://github.com/guptadolly458

The temporary 3D calendar/achievement placeholders will be replaced by the generated metrics.

## 6. Keep ShinigamiCode

Your project remains:

https://github.com/guptadolly458/ShinigamiCode

The profile already puts it first in **selected work**.

## 7. LeetCode badge

I included the LeetCode badge to match the reference design. Since I don't know your LeetCode username, it currently points to the generic LeetCode site.

When you have your profile URL, edit README.md and replace:

`https://leetcode.com/`

with your actual profile URL.

## 8. Change radar skill levels

Open:

`assets/skills.json`

Change the numbers whenever you want. Example:

```json
{
  "Java": 82,
  "C": 78,
  "DSA": 78,
  "Git": 72,
  "SQL": 62,
  "OOP": 76
}
```

The supplied radar SVGs are already generated from these starter values.

## 9. Important

The ZIP uses the visual/structural design of the referenced profile, but uses your uploaded photo, your username, your LinkedIn, and your own repositories/projects.
